# مشروع أفق (Horizon)
## منصة تقنية مالية شاملة - SalamHack 2026

هذا المستند هو المرجع الرسمي الوحيد للمشروع، ومكتوب بالكامل باللغة العربية.

---

## نظرة عامة

أفق هو نموذج أولي (MVP) في مجال التقنية المالية يتيح التحويل بين الأصول المختلفة داخل محفظة واحدة:

- الدولار الأمريكي (USD)
- الذهب الرقمي (GOLD_OZ)
- البيتكوين (BTC)

يركز المشروع على الشمول المالي وسهولة الاستخدام، مع دعم سيناريوهات هاكاثون SalamHack 2026 عبر بيئة Sandbox مستقرة وقابلة للعرض.

---

## المسارات التي يغطيها المشروع

يلبي المشروع المسارات الأساسية المطلوبة في الهاكاثون:

1. إرسال واستقبال الأموال: تحويل فوري بين الأصول مع رسوم واضحة.
2. أدوات المستقلين والمشاريع الصغيرة: نظام فواتير مرن مع الدفع بعملة والاستلام بأصل مختلف.
3. فهم المال وإدارته: ادخار تلقائي بالذهب (Round-up) + نصائح مالية ذكية.

---

## المميزات الرئيسية

- محفظة متعددة الأصول مع عرض الرصيد الحالي بشكل فوري.
- محرك تحويل عابر للأصول (Swap) مع احتساب رسوم 0.1% لكل عملية.
- سجل معاملات مفصل وآخر 50 عملية لكل مستخدم.
- محاكاة تحويل عبر الرسائل النصية (SMS) بصيغة أوامر موحدة.
- ادخار تلقائي بالذهب من كسور العمليات (Round-up).
- نظام فواتير للمستقلين مع رابط دفع مباشر.
- بطاقة افتراضية قابلة للإصدار والتجميد/إعادة التفعيل.
- صفحة Open Banking لمحاكاة ربط حساب بنكي وجلب معاملات تجريبية.
- نصائح مالية ذكية مبنية على توزيع المحفظة.
- واجهة ثنائية اللغة داخل التطبيق (عربي/إنجليزي)، بينما هذا الملف بلغة واحدة فقط (العربية).

---

## افتراضات Sandbox 2026

يعتمد المشروع حالياً على أسعار ثابتة (بدون مزود أسعار خارجي مباشر) لضمان ثبات العرض في الهاكاثون:

- 1 USD = 3.75 SAR
- 1 USD = 0.0005 GOLD_OZ
- 1 USD = 0.000015 BTC

كما أن التحقق KYC/AML مفترض أنه مكتمل مسبقاً للمستخدمين ضمن سياق بيئة الهاكاثون.

```text

   |
   | HTTP/JSON
   v

   |
   v
SQLite (تخزين دائم للمستخدمين، المحافظ، المعاملات، الفواتير، البطاقات)
```

---

## الأمان والتحقق

- التحقق من صحة المدخلات عبر نماذج Pydantic.
- منع القيم السالبة أو الصفرية في العمليات المالية.
- التحقق من كفاية الرصيد قبل تنفيذ التحويل أو دفع الفاتورة.
- توثيق رقمي تجريبي لكل عملية Swap عبر رمز توقيع (Digital Signature Code).
- جلسات دخول مبنية على Token بعد تسجيل الدخول.

## مرجع واجهات API

### المصادقة

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | /auth/register | إنشاء مستخدم جديد |
| POST | /auth/login | تسجيل الدخول واستلام Token |
| POST | /auth/logout | تسجيل الخروج وإبطال Token |

### المحفظة والأسعار

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | /wallet | جلب أرصدة المحفظة للمستخدم الحالي |
| GET | /prices | جلب الأسعار الحالية وسجل الأسعار |

### التحويل والرسائل

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | /swap | تنفيذ تحويل بين أصلين |
| POST | /simulate-sms-transfer | تنفيذ تحويل عبر أمر SMS محاكى |

### Open Banking

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | /open-banking/connect | محاكاة الربط البنكي + احتساب Round-up وإضافته كذهب |

### الاستشارات والسجل

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | /financial-advice | نصائح مالية مبنية على توزيع الأصول |
| GET | /transactions | سجل آخر 50 معاملة |

### الفواتير

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | /invoice/create | إنشاء فاتورة جديدة |
| GET | /invoice/{invoice_id} | عرض تفاصيل فاتورة |
| POST | /invoice/{invoice_id}/pay | دفع فاتورة |
| GET | /my-invoices | عرض فواتير المستخدم |

### البطاقة الافتراضية

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | /card/create | إصدار بطاقة افتراضية |
| GET | /card | جلب تفاصيل البطاقة |
| DELETE | /card/freeze | تجميد/إعادة تفعيل البطاقة |

توثيق API التفاعلي:

- http://127.0.0.1:8000/docs

## طريقة التشغيل

### المتطلبات

- Python 3.10 أو أحدث
- pip

### 1) تثبيت الاعتمادات

```bash
pip install -r requirements.txt
```

### 2) تشغيل الخادم الخلفي (FastAPI)

```bash
python -m uvicorn main:app --reload
```

الخادم يعمل على:

- http://127.0.0.1:8000

### 3) تشغيل الواجهة (Streamlit)

```bash
python -m streamlit run app.py
```

الواجهة تعمل على:

- http://localhost:8501
